# PDF-Chat-RAG

PDF-Chat-RAG is an intelligent, AI-powered document assistant that enables seamless interaction with your PDF files. Built using Next.js and a robust Retrieval-Augmented Generation (RAG) architecture, this application allows you to upload documents and query them using natural language, receiving precise, context-aware answers generated by LLMs.

Key Features
Intelligent RAG Pipeline: Efficiently processes and indexes your PDF content for accurate retrieval.

Next.js Framework: Provides a fast, responsive, and modern user interface.

Natural Language Interaction: Ask questions about your documents and get instant insights without manual searching.

Scalable Architecture: Designed for modularity and performance in handling document-based queries.

## 🚀 How to Run the Project locally

You will need to open two separate terminals to run the client and server at the same time.

### 1. Start the Backend (Server)
Navigate to the server directory, install dependencies, and start the server.
```bash
cd server
npm install
npm run dev  # (Change this to your actual start command)
